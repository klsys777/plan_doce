# ZJ\-关节模组CANFD通信协议\_sy

**指境关节模组通信协议CAN FD**



|项目|约定|
|---|---|
|适用范围|主站与ZJ关节模组之间的CAN FD通信|
|标识符|11 位标准 CAN ID；CAN FD 数据帧；BRS 开启。|
|默认比特率|仲裁段 1 Mbit/s，采样点83\.3%；数据段 2 Mbit/s，采样点 83\.3%|
|字节序|U16、U32、I32 和 IEEE 754 F32 均使用小端。|
|帧长度|除 PID 对象帧使用 DLC 16 外，其余协议帧统一使用 DLC 8。|
|数据格式|小端格式|



# 1 CAN FD及链路层

## 1\.1 ID定义

|**CAN ID**|**方向**|**名称**|**DLC**|**用途**|
|---|---|---|---|---|
|0x000|主站→全部|EMERGENCY\_STOP|8|广播急停。|
|0x0E0 \+ Node ID|主站→节点|OBJ\_REQ|8 / 16|普通对象为 8；PID 对象为 16。|
|0x100 \+ Node ID|节点→主站|OBJ\_RSP|8 / 16|长度与对应对象格式一致。|
|0x120 \+ Node ID|节点→主站|HEARTBEAT|8|节点在线与状态。|

Node ID当前设置有小范围为0\-21个节点有效，带有id的标识按 基址\+ID计算。例如节点7，则OBJ\_REQ的CAN ID为0x0E7 。

## 1\.2 电机模组中CAN FD头配置

|字段|设置|含义|
|---|---|---|
|Identifier|按上表计算|真正用于区分帧类型和节点。|
|IdType|FDCAN\_STANDARD\_ID|11 位标准标识符，不是业务帧类型。|
|TxFrameType|FDCAN\_DATA\_FRAME|数据帧。|
|DataLength|按本帧的实际字节数|例如 FDCAN\_DLC\_BYTES\_8 或 \_16。|
|BitRateSwitch|FDCAN\_BRS\_ON|数据段使用更高比特率。|
|FDFormat|FDCAN\_FD\_CAN|CAN FD 格式。|

对PID参数的配置的DLC为16，其他通用参数配置DLC均为8

|---|---|---|---|
|B0|B1 B2|B3\~B6|B7|

|**字节**|**字段**|**规则**|
|---|---|---|
|B0|TYPE|请求或应答类型。|
|B1～B2|INDEX|U16 小端；应答原样回显。|

## 2\.3 TYPE定义

|**TYPE**|**名称**|**DATA**|
|---|---|---|
|0x01|READ\_REQ|DATA=00 00 00 00|
|0x02|WRITE\_REQ|DATA 为拟写入值|
|0x81|READ\_RSP|DATA 为读取结果|
|0x82|WRITE\_RSP|DATA 回显已接受的对象值|
|0xFF|ERROR\_RSP|DATA 为 UINT32 错误码，小端模式|

# 4 广播协议

## 4\.1广播停止协议

可用来控制can总线上所有的电机进入停止状态

实例：

CAN ID = 0X000

DLC   = 8

DATA  = 01 00 01 00 00 00 00 00

|字节|数值|含义|
|---|---|---|
|B0|0X01|全局停止命令|
|B1|0x00|标志，未定义|
|B2\-B3|0x01 0x00|事件号|
|B4\-B7|0x00 0x00 0x00 0x00|保留字段|

B2\-B3  定义为事件序号，当前系统中未定义事件，目前统一使用0x01 0x00表示这一字段
