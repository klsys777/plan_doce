## 一、功能说明

### 1.1 功能描述

主要功能如表 1 所列。

**表 1 空心杯电机驱动器主要功能**

| 序号 | 功能名称 | 命令字 | 功能描述 |
|------|----------|--------|----------|
| 1 | 使能功能 | 0x38 | 根据通讯指令进行使能功能控制 |
| 2 | 速度环控制功能 | 0x32 | 根据通讯指令进行速度环功能控制 |
| 3 | 位置环控制功能 | 0x32 | 根据通讯指令进行位置环功能控制 |
| 4 | 回零功能 | 0x40 | 根据通讯指令进行回零功能控制 |
| 5 | 参数查询功能 | 0x35 / 0x37 | 根据通讯指令进行参数查询功能控制 |
| 6 | 参数配置功能 | 0x36 | 根据通讯指令进行参数配置功能控制 |
| 7 | 参数保存功能 | 0x39 | 根据通讯指令进行参数保存功能控制 |
| 8 | 磁编校准功能 | 0x41 | 根据通讯指令进行磁编校准功能控制 |
| 9 | 电机 ID 更改功能 | 0x42 | 根据通讯指令进行电机 ID 的更改功能 |
| 10 | 电机配置查询功能 | 0x43 | 根据通讯指令进行电机配置查询功能 |
| 11 | 速度环输出最大电流查询/设置功能 | 0x44 | 根据通讯指令进行速度环输出最大电流查询/设置功能 |

各项功能描述如下：

**(1) 使能功能：** 本产品具有使能功能。软件识别 0x38 命令中的模式字 CMD 进行电机使能功能的配置。当 CMD 为 1 时，为电机使能。此时响应其他控制指令的操作，按照速度环或位置环指令驱动电机运行。当 CMD 为 0 时，为电机不使能。此时电机处于停止就绪状态，不响应除使能指令以外的其他所有指令。

**(2) 速度环/位置环控制功能：** 本产品具有速度环、位置环控制功能。软件识别 0x32 命令中的模式字 CMD 进行速度环和位置环功能的配置。当模式字 CMD 为 1 时，为速度环控制功能。软件对 data[5] 和 data[6] 的数据进行解析，得到确切的速度控制值；同时对 data[7] 的数据进行解析，得到电机的控制方向。最后根据得到的速度和方向对电机进行驱动。当模式字 CMD 为 2 时，为位置环控制功能。软件对 data[5] 和 data[6] 的数据进行解析，得到确切的角度控制值；同时对 data[7] 的数据进行解析，得到电机的控制方向。最后根据得到的角度和方向对电机进行驱动。

**(3) 回零功能：** 本产品具有回零功能，软件通过识别 0x40 命令中的模式字 CMD。当模式字 CMD 为 1 时，进行回零操作。此时电机会按照命令规定方向持续运行，当运行到堵转状态之后，认为该位置为零位。

**(4) 参数查询功能：** 本产品具有参数读取功能，主要分为电机状态和配置参数两部分。软件识别 0x35 命令中的模式字 CMD，进行电机状态参数的回复；软件识别 0x37 命令中的模式字 CMD，进行电机配置参数的回复。

**(5) 参数配置功能：** 本产品具有参数配置功能，软件通过识别 0x36 命令中的模式字 CMD，对相关控制环路的 Kp、Ki 参数进行配置。

**(6) 参数保存功能：** 本产品具有参数保存功能，软件通过识别 0x39 命令中的模式字 CMD，对参数进行保存（暂时只保存速度环 KPKI、位置环 KPKI、电流环 KPKI、磁编偏差角度、速度环输出最大电流、软件版本和电机 ID）。

**(7) 磁编校准功能：** 本产品具有磁编校准功能，新电机在上电之后需要先空载进行磁编校准。软件识别 0x41 命令中的模式字 CMD，进行磁编校准，计算出磁编角度误差，并进行保存。在执行无误后，回复报文。

**(8) 电机 ID 更改功能：** 本产品具有电机 ID 更改功能。软件识别 0x42 命令中的模式字 CMD，进行电机 ID 和电机编号的更改。数据更改后，将新 ID 和电机编号进行存储，后续以新 ID 进行控制识别及数据回复。

**(9) 电机配置查询功能：** 初始化上电之后，软件识别 0x43 命令中的模式字 CMD，将电机 ID、电机编号和版本号进行上传（该指令为广播指令，所有电机均会响应，建议单设备调试使用，以确定电机 ID）。

**(10) 速度环输出最大电流查询/设置功能：** 初始化上电之后，软件识别 0x44 命令中的模式字 CMD，对速度环输出最大电流值进行查询和配置。

### 1.2 协议描述

#### 1.2.1 通信口参数配置

串口数据传输：

- 波特率：230400
- 停止位：1
- 数据位：8
- 奇偶校验：无

CRC8 采用 CRC8-MAXIM 的计算方法。

#### 1.2.2 使能控制

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |
|------|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|----------|
| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 保留 | 保留 | 保留 | 保留 | 保留 | CRC8 |

命令字 data[0]-data[1]：`0x38`

1. 模式字 CMD = 0：电机不使能。
2. 模式字 CMD = 1：电机使能。

#### 1.2.3 速度环/位置环控制

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |
|------|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|----------|
| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 数据高 8 位 | 数据低 8 位 | dir | 保留 | 保留 | CRC8 |

命令字 data[0]-data[1]：`0x32`

1. 模式字 CMD = 1：速度控制模式。后续数据为控制速度。0~32767 表示 0% 速度到 100% 基准速度。基准速度为 20000 rpm。当速度环运行时，有新的速度指令过来时，电机会以新的速度进行电机驱动。
2. 模式字 CMD = 2：位置控制模式。后续数据为角度增量。0~32767 表示 0° 到 180°（减速机输出的末端角度）。当位置环运行时，有新的角度过来时，电机会以当前位置为基准，重新按照新的角度进行驱动。例如上次角度为 +90°，运行到 45° 的时候，再给 +10° 的指令，最后电机会停止在 55° 位置附近。
3. data[7] dir = 0：正转；dir = 1：反转。当电机运行过程中，如果需要换向时，需要先使电机停下，设置新的转向，然后才会驱动电机按照新的转向运行。
4. 当速度环直接切换为位置环，或者位置环直接切换为速度环的时候，若电机转向没有变化，电机会直接切换到对应环路。

#### 1.2.4 回零控制（固定方向，固定转速）

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |

| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 保留 | 保留 | dir | 保留 | 保留 | CRC8 |

命令字 data[0]-data[1]：`0x40`

1. 模式字 CMD = 1：回零指令生效。
2. 模式字 CMD = 0：回零指令不生效。
3. data[6] dir = 0：正转回零；dir = 1：反转回零。

根据控制报文中模式字 CMD 的不同分为如下几种回复，同时 data[9] 表示该次回复数据对应的模式字 CMD 的状态。

**模式字 CMD = 1 的回复报文：**

1. 电流单位为 mA。

#### 1.2.8 参数保存

电机接收报文：命令字 data[0]-data[1]：`0x39`

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |
|------|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|----------|
| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 保留 | 保留 | 保留 | 保留 | 保留 | CRC8 |

1. 模式字 CMD = 1：执行保存指令。

电机回复报文：命令 `0xB0`

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |
|------|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|----------|
| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 保留 | 保留 | 保留 | 保留 | 保留 | CRC8 |

1. 模式字 CMD = 1：保存成功。
2. 模式字 CMD = 2：保存失败。
3. 模式字 CMD = 0：无保存指令（0x39 发送指令中模式字 CMD 不为 1 的情况下回复）。

#### 1.2.9 磁编校准功能

电机接收报文：命令字 data[0]-data[1]：`0x41`

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |
|------|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|----------|
| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 保留 | 保留 | 保留 | 保留 | 保留 | CRC8 |

1. 模式字 CMD = 0：回复当前磁编校准值。
2. 模式字 CMD = 1：执行磁编校准功能。

电机在校准完成后，电机回复报文：命令 `0xE0`

| 数据 | data[0] | data[1] | data[2] | data[3] | data[4] | data[5] | data[6] | data[7] | data[8] | data[9] | data[10] |
|------|---------|---------|---------|---------|---------|---------|---------|---------|---------|---------|----------|
| 内容 | 命令高 8 位 | 命令低 8 位 | 电机 ID 高 8 位 | 电机 ID 低 8 位 | 模式字 CMD | 磁编校准角度 CW | 磁编校准角度 CCW | 保留 | 保留 | 保留 | CRC8 |

1. 如果发送的模式字 CMD 为 0 时，为回复数据，则该数据的模式字 CMD 为 0，同时将磁编校准角度发送。
2. 如果发送的模式字 CMD 为 1 时，执行磁编校准功能，待校准完成后，将该数据帧进行回复。此时该数据的模式字 CMD 为 1，磁编校准角度为当前识别的校准角度。

#### 1.2.10 电机 ID 更改功能

电机接收报文：命令字 data[0]-data[1]：`0x42`

2. 模式字 CMD = 1：将新电机 ID 作为本电机 ID 进行保存并回复。

1. 电机 ID 为更改后的新 ID。
2. data[4] 中的模式字 CMD 为 1，表明更改完成。

## 二、操作手册

### 2.1 操作步骤

**1.** 电机上电后，上位机需要发送一帧广播数据，用于获取电机的 ID 和编号。在广播获取电机 ID 后，后续所有的控制指令均以该电机 ID 进行控制，具体数据如下所示。

```
发送数据：0x00 0x43 0x00 0x01 0x01 0x00 0x00 0x00 0x00 0x00 0x25
接收数据：0x00 0xD0 0x00 0xAF 0x01 0x02 0xAB 0xCD 0x00 0x00 0x3D
```

- 电机 ID：175 (0x00AF)
- 软件版本：3
- 电机编号：43981 (0xABCD)

**2.** 第一次上电后，需要对电机 ID 和编号进行更改。更改完成后，后续所有的控制指令均以新电机 ID 进行控制，具体数据如下所示。

```
发送数据：0x00 0x42 0x00 0xAF 0x01 0x00 0x08 0x55 0xAA 0x00 0xDD
接收数据：0x00 0xC0 0x00 0x08 0x01 0x55 0xAA 0x00 0x00 0x00 0x44
```

- 电机 ID 更改为：8 (0x0008)
- 电机编号更改为：21930 (0x55AA)

**3.** 第一次上电后，需要对磁编进行查询。如果磁编查询结果为 0，说明没有进行磁编校准，则需要进行磁编校准，具体数据如下所示。

```
发送数据：0x00 0x41 0x00 0x08 0x00 0x00 0x00 0x00 0x00 0x00 0x8F
接收数据：0x00 0xE0 0x00 0x08 0x00 0x00 0x00 0x00 0x00 0x00 0xEB
```

查询得知：电机磁编正转校准角度为 0；电机磁编反转校准角度为 0。

**4.** 当需要进行磁编校准时，首先要先发送使能指令，使电机运行进行控制，然后再发送磁编校准指令，进行磁编校准操作。在磁编校准完成，接收到正确的磁编校准角度后，发送失能指令（所有控制电机的指令在发送前都要发送使能指令；在结束控制之后要发送失能指令，避免电机误动）。

```
使能指令：0x00 0x38 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0x4C
磁编校准：0x00 0x41 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0xB8
接收数据：0x00 0xE0 0x00 0x08 0x01 0x5E 0x90 0x4D 0x10 0x00 0xC7
失能指令：0x00 0x38 0x00 0x08 0x00 0x00 0x00 0x00 0x00 0x00 0x7B
```

在接收到使能指令后，进行磁编校准。电机磁编结果为正转校准角度为 24208；电机磁编反转校准角度为 19728。

**5.** 磁编校准之后就可以进行电机正常的速度环、位置环控制。以下分别举例说明速度环控制和位置环控制的具体指令。

速度环控制 15000 rpm，正转：

```
使能指令：0x00 0x38 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0x4C
速度指令：0x00 0x32 0x00 0x08 0x01 0x60 0x00 0x00 0x00 0x00 0x51
（此时电机会按照 15000 rpm 持续正转）
失能指令：0x00 0x38 0x00 0x08 0x00 0x00 0x00 0x00 0x00 0x00 0x7B
```

位置环控制 90°，正转：

```
使能指令：0x00 0x38 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0x4C
位置指令：0x00 0x32 0x00 0x08 0x02 0x40 0x00 0x00 0x00 0x00 0xF0
（此时电机会正转 90° 并停下）
失能指令：0x00 0x38 0x00 0x08 0x00 0x00 0x00 0x00 0x00 0x00 0x7B
```

**6.** 上位机可以通过固定指令，对电机配置及运行状态等参数进行状态查询。具体如下所示：

1）运行状态查询：

```
发送数据：0x00 0x35 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0x17
接收数据：0x00 0x70 0x00 0x08 0x01 0x00 0x00 0x02 0x55 0xAA 0xDD
```

电机当前处于就绪状态，无故障，软件版本号为 3，软件编号为 21930。

2）电流参数查询：

```
发送数据：0x00 0x35 0x00 0x08 0x02 0x00 0x00 0x00 0x00 0x00 0x4E
接收数据：0x00 0x70 0x00 0x08 0x02 0x00 0x00 0x00 0x00 0x00 0x92
```

电机当前 D 轴电流为 0 mA，Q 轴电流为 0 mA。

3）控制模式查询：

```
发送数据：0x00 0x35 0x00 0x08 0x03 0x00 0x00 0x00 0x00 0x00 0x79
接收数据：0x00 0x70 0x00 0x08 0x03 0x00 0x00 0x00 0x00 0x00 0xA5
```

电机当前无控制，速度/角度为 0。

4）电压参数查询：

```
发送数据：0x00 0x35 0x00 0x08 0x04 0x00 0x00 0x00 0x00 0x00 0xFC
接收数据：0x00 0x70 0x00 0x08 0x04 0x00 0x79 0x00 0x00 0x00 0x1B
```

电机当前母线电压为 12.1 V。

**7.** 上位机可以通过固定指令，对电机参数存储。具体如下所示：

```
存储指令：0x00 0x39 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0xE8
接收数据：0x00 0xB0 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0xBC
```

**8.** 电机具有回零功能，根据指令按照固定转速进行正转/反转，实现回零功能。

```
使能指令：0x00 0x38 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0x4C
正转回零：0x00 0x40 0x00 0x08 0x01 0x00 0x00 0x00 0x00 0x00 0x1C
```

**9.** 电机查询/设置速度环输出电流最大值功能，通过固定指令实现该功能。

```
查询指令：0x00 0x44 0x00 0xAF 0x00 0x00 0x00 0x00 0x00 0x00 0x42
查询回复：0x00 0xF0 0x00 0xAF 0x00 0x03 0xE8 0x00 0x00 0x00 0x81
设置指令：0x00 0x44 0x00 0xAF 0x01 0x01 0xF4 0x00 0x00 0x00 0xC7
设置回复：0x00 0xF0 0x00 0xAF 0x01 0x01 0xF4 0x00 0x00 0x00 0x1F
```

电机当前速度环输出电流最大值测试后，根据需要选择是否将该设定值进行存储。
